# RIVER · 德州扑克胜率与行动路线 GUI

在本机浏览器中研究自己的手牌、公共牌和可见对手行动。提供多人摊牌胜率与单挑行动路线分析。运行时零第三方依赖，所有计算由浏览器后台 Worker 完成，不上传牌局。

## 启动

需要 Node.js 18 或更新版本。

```sh
npm start
```

打开 http://127.0.0.1:5173 。自定义端口：`PORT=5180 npm start`。不需要安装依赖即可使用 GUI 和运行单元测试；请通过本地服务器访问，不直接双击 HTML。

## 使用

1. 点击手牌选择自己的两张牌；点击公共牌设置翻牌 3 张、转牌 4 张或河牌 5 张。翻牌前留空。已使用牌自动禁用。
2. 胜率模块支持 1–8 个对手：通常让其手牌留空，模拟剩余牌中的均匀随机组合。指定对手手牌只适用于已知摊牌的复盘。
3. 行动路线模块先保持单挑且对手手牌留空。填写底池、有效筹码、当前需跟注金额和位置，选择对手范围与风格。
4. 添加对手已经发生的行动。街次取当前公共牌的对应前缀，严格按街次先后录入。请包含最新的对手下注作为历史证据；当前需跟注字段用于记账，不会自动重复更新范围。
5. 点击模拟，比较不同根节点行动在三种后续策略下的 EV。点击行动查看对手第一步回应与常见完整路径。相同种子和输入可复现结果；可导出 JSON 配置和报告。

`BB` 表示大盲单位。`s / h / d / c` 分别表示黑桃、红桃、方块、梅花；`T` 表示 10。

## 采用的计算方式

### 胜率

- 标准 52 张牌，比较七张牌中最强五张。支持 A2345 顺子、同花顺、踢脚牌和公共牌平分底池。
- 合法发牌结果不超过 150,000 时精确枚举；其余牌局进行无放回蒙特卡洛抽样。
- 独赢率 + 平局率 + 落败率 = 100%。权益 = 每次独赢的 1 加上 k 人平局时的 1/k，再取平均。
- 模拟展示 Hoeffding 的 95% 保守权益误差上界：`100 × sqrt(ln(40)/(2N))` 个百分点。精确枚举无抽样误差。随机对手假设不是现实对手范围。

### 范围与可见行动

- 范围枚举最多 1,326 个起始组合，去除自己的牌与公共牌占用的组合。
- “较宽 / 较紧”取翻牌前启发式评分前约 40% / 15%，边界同分组合全部保留，避免花色偏置；它们不是经过 GTO 求解的开局表。
- 自定义范围支持 `AA`、`QQ+`、`AKs`、`AKo`、`AK`、`AJs+`、`AsKh:0.5`。非对子 `+` 固定第一张点数、提高第二张点数，`AJs+` 为 AJs/AQs/AKs。多个条目重叠时后者覆盖权重。不支持 `22-99` 一类区间语法。
- 对每个合法手牌应用 `后验权重 ∝ 先验权重 × ∏ P(已观察行动 | 手牌、当时公共牌、风格)`，再归一化。行动似然使用公开在 `src/strategy.js` 的启发式模型。
- 四种对手风格控制诈唬、主动下注、跟注和加注概率；手牌评分使用自己的牌、当前公共牌、成牌类别与听牌，不读取对手底牌或尚未发出的公共牌。

### 行动树与 EV

这是**可解释的对手模型 + 路线模拟**，尚不是 CFR / GTO solver，无需离线训练。

- 行动模拟仅限单挑，覆盖翻牌前至河牌。未来牌无放回抽样，按街次揭示。
- 根节点比较合法的弃牌、跟注、过牌、33% / 75% / 100% 底池下注及有效全下。加注使用“补足跟注金额 + 按跟注后底池计算的加注增量”；增量满足最小加注，短全下除外。每街最多一次加注，重复尺度合并。
- 三种后续策略为谨慎控池、价值优先、积极施压，均只依据自己的牌、已发出的公共牌和当前下注作决策。它们不是学习得到的均衡策略，也不是对隐藏手牌最优回应。
- 当前底池包含已经投入的所有筹码，包括对手当前下注。有效筹码表示从当前决策起、对手本次下注前双方相同的有效预算：你剩余 S，对手剩余 S−C。当前需跟注 C 模型化为一笔新下注；不重建当前街既往加注链。
- IP 且 C=0 时，假设对手已经过牌；OOP 且 C=0 时由你先行动。后续各街按位置行动。
- EV 以当前决策为零点：`终局分得底池 − 从现在起你的投入`。之前投入已是沉没成本，立即弃牌 EV=0。对手弃牌赢取整个当前底池；全下后直接发完公共牌。
- 根节点行动与三种后续策略使用共同随机数降低对比噪声。展示近似 95% 正态抽样区间 `±1.96 × 标准误`。区间不包含对手模型错误，亦不是多个行动排序的联合置信保证。
- 当前版本没有抽水、边池、ICM、多人数行动模型或均衡可利用度指标。最高模拟 EV 仅适用于设定模型。

## 验证与开源基准

```sh
npm test
npm ci --ignore-scripts
npm run benchmark
```

单元测试不依赖安装包。基准使用锁定的 MIT 开源 `pokersolver@2.1.4`，仅作为开发依赖，不进入 GUI 运行路径。

- 25,000 组随机七张牌的牌型对照。
- 5,000 场共享公共牌的 2–8 人牌局，比较赢家集合和平局。
- 4 个河牌场景分别穷举全部 990 个对手组合，使用独立评估器核对权益。
- 4 个河牌行动场景：逐个合法根行动 × 三种后续策略，与同一模型完整响应树的精确积分比较。另对比被动过牌／跟注基线与模拟选中的行动，分别用精确积分评估。

实际结果见 [benchmarks/REPORT.md](benchmarks/REPORT.md) 和 `benchmarks/latest.json`。界面展示最近一次基准摘要。基准能验证数值正确性，不能证明真实牌局盈利或接近 GTO。

## 后续 CFR 路线

传统 CFR 通过反事实遗憾最小化迭代求解策略，需要双方范围和一个有限下注树；无需神经网络训练。Deep CFR 等神经网络变体才涉及训练模型。本版先完成实用分析，CFR 尚未实现。

建议下一阶段先做单挑河牌的有限树 CFR，再扩展转牌／翻牌；提供策略混合频率、迭代次数、EV 与可利用度/收敛指标。独立验证可选：

- [OpenSpiel](https://github.com/google-deepmind/open_spiel)：Kuhn/Leduc 的游戏价值、CFR 和 exploitability 基准。
- [Desktop Postflop](https://github.com/b-inary/desktop-postflop) / [postflop-solver](https://github.com/b-inary/postflop-solver)：匹配范围、底池、筹码、下注树、抽水后对照 Hold'em 翻后策略。上游说明其开源开发于 2023 年 10 月暂停。

## 文件结构

- `src/poker.js`：牌型评估、精确枚举、胜率模拟。
- `src/strategy.js`：范围解析、行动似然、合法行动、筹码状态、逐街模拟与河牌精确 EV。
- `src/app.js` / `src/strategy-ui.js`：选牌与分析界面。
- `src/*worker.js`：可取消的后台计算。
- `test/`：评估器、抽样、范围、筹码记账、信息隔离与终止性测试。
- `scripts/benchmark.mjs`：独立开源基准与报告生成。
- `PLAN.md`：实施规划与阶段进度。
